# Content Zavod

Продукт для генерации контент-планов и статей для медиаплощадок (Дзен, VC), с рабочим процессом через Telegram-бота для команды контент-менеджеров.

## Language

**Тема**:
Одна идея из недельного плана — исследуется один раз (факты, ракурс, ключевые слова), затем адаптируется под каждую целевую Площадку. Единица планирования. Появляется одним из двух способов: автоматически из растущих запросов Wordstat в рамках Ниши (с проверкой на повтор с историей уже сделанных Тем), или вручную — любой участник команды может предложить свою Тему, минуя автоподбор.
_Avoid_: Пост, идея, топик

**Ниша**:
Тематическая область, в границах которой подбираются Темы и пишутся Статьи. По умолчанию — маркетинг; Владелец может посмотреть и изменить её через `/niche`/`/set_niche`.
_Avoid_: Тематика, домен, вертикаль

**Направления**:
Список seed-запросов для Wordstat-подбора растущих Тем внутри Ниши. По умолчанию — фиксированный список маркетинговых запросов; Владелец может посмотреть и изменить его целиком через `/directions`/`/set_directions`. В отличие от Ключа, не имеет частотности — это вход для Wordstat-поиска, а не его результат.
_Avoid_: Ключевые слова, теги, категории, Ключ

**Персона**:
Автор, от чьего лица пишутся все Статьи независимо от Площадки. Задаётся либо выбором из готового Пресета, либо своим описанием; по умолчанию — практикующий маркетолог. Владелец может посмотреть и изменить её через `/persona`/`/set_persona`. Тон под конкретную Площадку накладывается поверх Персоны, не заменяет её.
_Avoid_: Голос, стиль, тон (тон — это про Площадку, Персона — про автора)

**Пресет**:
Готовая Персона из закрытого каталога, выверенная заранее и неизменяемая. Владелец может выбрать Пресет или задать свою Персону, но не отредактировать сам Пресет.
_Avoid_: Шаблон, профиль

**Проект**:
Telegram-канал или сайт заказчика, куда ведёт CTA в конце каждой Статьи: одна ссылка на весь бот и короткое описание, что там. Необязателен — без него Статьи пишутся без CTA. Ссылку в итоговый текст ставит код, а не модель: ровно один раз, символ в символ. Владелец смотрит и меняет его через `/project`/`/set_project`, убирает — `/set_project -`.
_Avoid_: Канал (как синоним — путается с Площадкой), ссылка, промо

**Настройки**:
Ниша, Персона, Направления и Проект вместе — то, что Владелец задаёт один раз и меняет по необходимости, и что действует на каждую последующую генерацию. Расписание сюда не входит: его изменение перепланирует уже назначенный запуск, а Настройки просто читаются следующей генерацией.
_Avoid_: Конфигурация, параметры, опции

**Статья**:
Готовый текст под конкретную Площадку, порождённый из одной Темы. Одна Тема даёт несколько Статей (по одной на Площадку) — с разной структурой и формулировками, а не просто разным оформлением одного текста.
_Avoid_: Материал, пост, адаптация (как существительное)

**Площадка**:
Целевой сайт публикации со своими требованиями к формату и тону. На MVP: Дзен и VC. Т-Ж не входит в MVP (см. ADR).
_Avoid_: Сайт, платформа, канал

**План**:
Недельный набор из 2-4 Тем, формируется автоматически по расписанию или вручную, живёт одним каноничным сообщением в групповом чате команды. Проходит через согласование Контент-менеджерами перед тем, как по нему начинают генерироваться Статьи.
_Avoid_: Контент-план, календарь

**Роль**:
Одна из двух: Владелец или Контент-менеджер. Определяет, какие команды и колбэки бота доступны участнику; резолвится по telegram id при каждом обращении, не хранится в сессии.
_Avoid_: Права, доступ, permission

**Контент-менеджер**:
Роль без доступа к настройкам/промптам — генерирует и утверждает План, утверждает или запрашивает Перегенерацию каждой Статьи, выгружает готовые файлы.
_Avoid_: Менеджер, редактор

**Владелец**:
Роль с доступом к настройкам и промптам генерации.
_Avoid_: Админ, суперюзер

**Версия**:
Один конкретный прогон генерации Статьи — со своим промптом, моделью, параметрами, токенами и стоимостью. Перегенерация создаёт новую Версию, а не затирает предыдущую.
_Avoid_: Попытка, ревизия

**Перегенерация**:
Запрос Контент-менеджера создать новую Версию уже сгенерированной Статьи взамен неудачной.
_Avoid_: Регенерация, повтор

**Выгрузка**:
Момент, когда готовая Статья отдаётся Контент-менеджеру файлом (.docx/.md, на выбор) для дальнейшей правки во внешнем редакторе. Правки, сделанные после Выгрузки, в систему не возвращаются (вне MVP). Происходит и сразу при генерации, и повторно из Истории (см. ADR).
_Avoid_: Экспорт, скачивание

**Исследование**:
Сбор фактов по Теме перед написанием Статей: поиск в Yandex Search API → загрузка найденных страниц → модель выписывает факты строго из текста страницы, каждый с дословной цитатой → код оставляет только факты, чья цитата действительно есть на странице. Делается один раз на Тему (вместе с общим аутлайном) и переиспользуется всеми Площадками и Перегенерациями, поэтому Статьи одной Темы стоят на одних и тех же фактах. Если поиск недоступен или проверяемых фактов не нашлось — Статья пишется без конкретных цифр и фактов, а карточка Статьи в Telegram предупреждает редактора (в сам текст пометка не попадает).
_Avoid_: Ресёрч, research bundle (в разговоре)

**Evidence**:
Один факт из Исследования: утверждение + дословная цитата + URL страницы. Только по Evidence Статья может приводить цифры и факты (модель ставит маркер `[E1]`, код превращает его в сноску `[1]`); всё остальное — рассуждение или явно помеченное мнение автора.
_Avoid_: Пруф, доказательство, факт (как термин)

**Страница для чтения**:
Публичная страница Статьи на telegra.ph — кнопка «📖 Читать» в карточке Статьи, чтобы прочитать текст целиком прямо в Telegram (Instant View), не скачивая файл. Одна на Статью: каждая новая Версия обновляет ту же страницу, ссылка не меняется. Необязательна — если telegra.ph недоступен, карточка приходит без кнопки. В отличие от Выгрузки, это не файл для правки, а только чтение; и она публична до выхода Статьи на Площадке (принято осознанно, #92).
_Avoid_: Telegraph-ссылка, превью (превью — это ~800 символов в самой карточке)

**Источник**:
Страница из Исследования, на которую опирается хотя бы одно Evidence, процитированное в Статье. Список «Источники» в конце Статьи составляет код, а не модель; любые другие ссылки, кроме Проекта, из текста удаляются.
_Avoid_: Ссылка, референс

**Ключ**:
Поисковый запрос с частотностью, полученной через Yandex Search API (Wordstat), используемый при генерации Темы и Статьи.
_Avoid_: SEO-ключ, запрос
