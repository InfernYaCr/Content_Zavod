# PostgreSQL вместо SQLite

Генерация Статьи вынесена в отдельный процесс-воркер (см. ADR-0004), который читает и пишет ту же БД параллельно с процессом Telegram-бота. SQLite не рассчитан на конкурентную запись из нескольких процессов и на этом масштабе стал бы источником блокировок и порчи данных. Выбрали PostgreSQL, несмотря на то что для одного VPS с небольшой нагрузкой SQLite выглядел бы "очевидным" выбором.
