# Очередь задач и отдельный процесс-воркер

Генерация одной Статьи — это многошаговый пайплайн (исследование → аутлайн → черновик → рерайт; с #94 исследование и аутлайн делаются один раз на Тему) плюс обложка, порядка 10+ вызовов внешних API и минуты работы. Хендлер aiogram не переживёт рестарт деплоя или падение процесса — работа потеряется без следов. Вместо синхронной генерации внутри хендлера бота ввели таблицу задач в БД (`queued/running/failed/done`, счётчик попыток, идемпотентность) и отдельный процесс-воркер, который её разбирает. Бот только ставит задачи в очередь и уведомляет о результате.
