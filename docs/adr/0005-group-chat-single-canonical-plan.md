# Групповой чат с одним каноничным сообщением плана

> **Заменён ADR-0015** (2026-10-12): групповых чатов и нескольких Контент-менеджеров больше нет. У каждого своё Пространство в личке с ботом. «Одно каноничное сообщение Плана на неделю» (send-once/edit-after, Хаб) остаётся, но в личном чате Владельца Пространства.

При нескольких Контент-менеджерах рассматривали личные чаты каждого с ботом или один групповой чат с общим сообщением Плана. Личные чаты потребовали бы синхронизации состояния между менеджерами (правка одного не видна другому, гонки при одновременном утверждении). Выбрали групповой чат с одним каноничным сообщением План — все менеджеры видят и правят одно и то же состояние, конфликты видимы сразу, а не расходятся молча.
