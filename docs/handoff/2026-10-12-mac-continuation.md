## Решения владельца (полностью — в #118 и #128)

- Пространства только личные: без коллег, групп и заявок. Роль Контент-менеджер упраздняется.
- Доступ открыт любому пользователю с пробным Лимитом: **1 План + 8 Статей**; «✏️ Доработать» списывает одну Статью. Глобальный администратор задаётся telegram id в env.
- Старые данные не переносятся, начинаем с чистого листа.
- Пока работаем **без обложек** (`YANDEX_COVERS=off`).
- **Направления убираются совсем.** Бот сам строит Карту Ниши по Нише и Аудитории. Свою Тему пользователь предлагает через «Предложить Тему». В Плане всегда 3 Темы. Новости Ниши берём любые. Квоту Wordstat пока не поднимаем, но ответ 429 не должен ронять План.
- Бот работает на MacBook владельца.

## Что дальше

### 1. Ключи Yandex (делает владелец, ты ведёшь по шагам)

В новом облаке ([консоль](https://console.yandex.cloud)):
1. Создать каталог `content-zavod`, сняв галочку «Создать сеть по умолчанию».
2. В этом каталоге: IAM → «Создать сервисный аккаунт» → `content-zavod-bot`.
3. Каталог → «Права доступа» → «Настроить доступ» → сервисный аккаунт → роли `ai.languageModels.user`, `ai.imageGeneration.user`, `search-api.webSearch.user`. Wordstat работает с этой же ролью.
4. Сервисный аккаунт → «Создать новый ключ» → «Создать API-ключ». Область действия: `yc.ai.languageModels.execute`, `yc.ai.imageGeneration.execute`, `yc.search-api.execute`.
5. ID каталога и секрет ключа владелец сам вписывает в `~/content-zavod/.env` (`YANDEX_FOLDER_ID=`, `YANDEX_API_KEY=`). **Не в чат.**
6. Биллинг → «Бюджеты»: 1000 ₽ в месяц на каталог `content-zavod`, уведомления на 50, 80 и 100 %.

Источники и детали — в отчёте сверки документации: роли, scope, цены, поведение при долге. Кратко они есть и в `.env.example`.
